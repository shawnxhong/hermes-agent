## Current limitation: exact supported English command forms

Recommended: `stop playback`, `stop music`, `stop video`.
Use these commands as standalone plain-text Feishu messages. Matching is
case-insensitive, permits outer whitespace and trailing `.`, `!`, `?`.
Other explicitly supported forms include `Please stop playback`,
`Could you stop the music please?`, `Stop playback again.`.

This is full-string pattern matching, NOT arbitrary semantic interpretation.
Chinese `停止播放`, `stop playback, please`, bare `stop it`, quoted commands,
negated commands and compound tasks do not enter the deterministic stop policy.
Outside the supported forms, the ordinary model path may falsely state playback
stopped without executing a tool. Do not treat a textual acknowledgement alone
as evidence of stopping. This limitation is accepted, not fixed in this release.
The policy applies only to Feishu; no equivalent voice-channel change is claimed.

## Known latency issue

FEISHU-MEDIA-STOP-LATENCY remains open: stopping can exceed 20 seconds. This
implementation still waits for a model request before native tool execution;
it is not an immediate hardware-style stop. No new latency guarantee.
