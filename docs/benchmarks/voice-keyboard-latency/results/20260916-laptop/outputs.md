```python
def remove_duplicates_preserve_order(input_list):
    """
    Removes duplicates from a list while preserving the original order.

    Args:
        input_list: List of elements (must be hashable)

    Returns:
        A new list with duplicates removed, preserving original order
    """
    seen = set()
    result = []

    for item in input_list:
        if item not in seen:
            seen.add(item)
            result.append(item)

    return result
```

**Example usage:**
```python
my_list = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
result = remove_duplicates_preserve_order(my_list)
print(result)  # Output: [3, 1, 4, 5, 9, 2, 6]
```

## Complexity Analysis

### Time Complexity: O(n)
- We iterate through each element in the input list exactly once
- For each element, checking if it exists in a set is O(1) on average
- Adding to the result list is amortized O(1)
- Total: n iterations × O(1) per operation = **O(n)**

### Space Complexity: O(n)
- The `seen` set can contain at most n unique elements
- The `result` list can contain at most n unique elements
- Total: O(n) space for both data structures = **O(n)**

## Why This Approach?

This method is optimal because:
1. **Hash sets provide O(1) average case lookups** - much faster than linear searches
2. **Order preservation** - we only add items when they first appear
3. **Single pass** - we process each element exactly once
4. **Memory efficient** - only stores what we need to track

## Edge Cases Handled:
- Empty lists: returns empty list
- Single element: returns same list
- All duplicates: returns list with unique elements only
- Mixed data types: works with any hashable types (strings, numbers, tuples)

The function assumes all elements are hashable (which includes strings, numbers, and tuples, but not lists or dictionaries). If you need to handle unhashable types, you'd need a different approach using `result.count()` or converting elements to strings for comparison.

The sky looks blue due to **Rayleigh scattering**:

1. Sunlight appears white but contains all colors of the rainbow
2. When sunlight enters Earth's atmosphere, it collides with gas molecules (mostly nitrogen and oxygen)
3. Shorter wavelengths (blue and violet) scatter more easily than longer wavelengths (red, orange, yellow)
4. Our eyes are more sensitive to blue than violet
5. The scattered blue light reaches our eyes from all directions, making the sky appear blue

This is why sunsets are red/orange - at sunset, sunlight travels through more atmosphere, scattering away the blue and letting the longer red wavelengths through.

**RAM (Random Access Memory)** and **Storage** serve fundamentally different purposes:

## RAM - The "Working Memory"
- **Purpose**: Temporarily holds data actively in use by programs and the operating system
- **Speed**: Very fast (nanoseconds)
- **Volatility**: Volatile - loses all data when power is turned off
- **Capacity**: Typically 4-32GB for consumer devices
- **Analogy**: Like the workspace on your desk - everything you're actively using

## Storage - The "Long-term Memory"
- **Purpose**: Permanently stores files, programs, and the operating system
- **Speed**: Much slower (milliseconds)
- **Volatility**: Non-volatile - retains data without power
- **Capacity**: Typically 256GB-2TB+ for consumer devices
- **Analogy**: Like the filing cabinet where you keep things when not in use

## Key Differences:

| Feature | RAM | Storage |
|---------|-----|---------|
| Data persistence | Loses data on power-off | Keeps data permanently |
| Speed | Very fast (GB/s) | Slower (MB/s) |
| Cost per byte | Expensive | Cheap |
| Main function | Active program/data | File storage |

## Practical Example:
When you open a large video editor:
- The program loads from **storage** into **RAM**
- Your video files are read from **storage** into **RAM** as you edit
- When you save, data moves from **RAM** back to **storage**
- When you shut down, **RAM** clears but **storage** keeps your saved work

Think of it this way: RAM is for working on something right now; storage is for keeping things for later.
