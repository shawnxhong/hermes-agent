# AISP C++ SDK 0.4.0 integration

The EOS bridge is compiled against the supplied Ubuntu 26.04 C++ runtime
v0.4.0-261014-59779, preserving the native AISP live-asr / MediaSession path.
SDK source and binary archives remain private assets; the paired ops repository
contains the hash lock and offline builder. Python wheels are not used:
their OpenVINO dependency metadata excludes their bundled 2026.4 runtime.

Pin existing effective behavior: English ASR on GPU, CPU VAD, 128 generated
tokens, 500 ms audio chunks, 2000 ms capture backlog and 4000 ms render backlog.
The 2000 ms baseline input limit was confirmed in the installed 0.3.6 library;
its older documentation incorrectly says 4000 ms. The new SDK retains the
monotonic audio timestamp epoch, so the existing post-cue EOS fence still applies.
Session callbacks remain registered on MediaSession, which owns the callback slot.

Keep the CLI EOS image, warmup, scenes, models, OVMS, ASR and TTS unchanged.
This is a local candidate until physical voice/panel and reboot acceptance.
Rollback swaps the AISP sidecar back to SDK 0.3.6; no state migration is required.
