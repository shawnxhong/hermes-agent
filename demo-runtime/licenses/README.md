# AISP SDK license

The SDK author selected Apache License 2.0 on 2026-11-12. The public installer
uses a new source archive with that license, preserving copyright notices.
The SDK source checksum is pinned in `../locks/sdk-build.json`.

`aisp-sdk-license-change.json` lists the modified source entries. Changes are
license headers, Python package license metadata, and English/Chinese release
license statements. The archive additionally includes LICENSE and LICENSING.md.
Implementation code is unchanged. All 33 existing `third_party/` entries remain
byte-identical and retain their existing notices and licenses. The top-level
license does not relicense third-party components or downloaded model weights.

Historical source copies in offline dependency bundles are retained for
provenance; the newly licensed `sdk.zip` is the source compiled by the installer.
The public materials release contains no service credentials or runtime history.
